# 🚀 NovaTech

NovaTech is a modern and responsive e-commerce website designed for technology enthusiasts. The platform provides an intuitive shopping experience for browsing and exploring the latest tech products, including laptops, smartphones, audio devices, and gaming accessories.

## 📖 About The Project

NovaTech was developed as a front-end e-commerce prototype to showcase a clean user interface, modern design principles, and organized product categorization. The website focuses on delivering a professional shopping experience while maintaining simplicity and responsiveness.

## ✨ Features

- 🏠 Modern Home Page
- 📱 Product Categories Section
- 💻 Laptops Collection
- 📲 Smartphones Collection
- 🎧 Audio Devices Collection
- 🎮 Gaming Accessories Collection
- ⭐ Featured Products Section
- 📄 About Page
- 📞 Contact Page
- 📱 Responsive Design
- 🎨 Clean and Professional UI

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Design Features
- Responsive Layout
- Flexbox & Grid
- Modern Card Components
- Smooth Hover Effects
- Mobile-Friendly Navigation

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Prathmesh1uchiha/web.git
```

### Navigate to Project Folder

```bash
cd web
```

### Run the Project

Simply open:

```bash
index.html
```

or use VS Code Live Server:

```bash
Right Click → Open with Live Server
```
