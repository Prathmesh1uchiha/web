# 🛒 NovaTech E-Commerce Website

A simple e-commerce website built using React and Vite.

## 🚀 Features

- Responsive Navbar
- Hero Section
- Categories Section
- Featured Products
- Testimonials
- About Page
- Contact Page
- Footer

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- CSS
